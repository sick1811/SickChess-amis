# SickChess – version pour les amis

Jeu d'échecs pour Windows (entraînement, analyse, jeu en ligne entre amis Steam).

**Installer :** télécharger [SickChess_Installation.exe](https://github.com/sick1811/SickChess-amis/releases/latest/download/SickChess_Installation.exe), le lancer, puis ouvrir SickChess depuis l'icône du Bureau. Aucun droit administrateur n'est demandé.

Le jeu se met ensuite à jour tout seul depuis le menu.

**Jouer en ligne :** Steam doit être ouvert. Ouvrir SickChess **avant** d'accepter l'invitation d'un ami (ou taper le code du salon).
